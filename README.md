# 千禧冲浪站 · WEB SURFER 1999

90 年代互联网风格的导航网站与完整站长后台。原生 HTML、CSS、JavaScript + Node.js，无第三方运行依赖。

## 本地启动

需要 Node.js 22 或更高版本：

```sh
npm run dev
```

- 前台：http://localhost:3000
- 后台默认关闭，不会出现在前台链接或普通页面路径中。需要管理时，用下面的命令显式开启：

```sh
npm run dev:admin
```

开启后默认地址为 http://localhost:3000/admin；也可以使用仅自己知道的路径：

```sh
ADMIN_ENABLED=1 ADMIN_PATH=/control-room npm run dev
```

关闭后台时，管理页、管理脚本和所有管理接口都会返回 404。不要把后台路径当作唯一防线，真正的保护仍是管理员密码、仅绑定本机和会话校验。
- 如端口被占用：`PORT=3001 npm run dev`
- `npm start` 为不自动重启的运行方式。

首次打开已启用的后台时创建自己的管理员账号，密码至少 10 位。没有默认用户名或密码。账号仅在本机初始化，之后登录才能管理数据。服务器绑定 `127.0.0.1`，用于本地运行，不直接对公网开放。

## 前台

- Windows 95 窗口、IE 地址栏、蓝色标题栏、老式网页目录、桌面任务栏。
- 两级分类、名称/网址/简介搜索、分页、目录放大。
- 我的收藏、随机漫游、热门推荐、精选网站、友情链接。
- 本地音乐电台：自动读取 `data/mp3/*.mp3`，支持播放、暂停、切曲、停止、进度、静音；目录为空或文件无法解码时使用内置合成旋律。
- 桌面、平板、手机布局，原有浏览器收藏继续可用。
- Win98 开始菜单：附件 → 扫雷、贪吃蛇。扫雷支持首步安全、右键/F 键插旗；贪吃蛇支持方向键/WASD、暂停和重新开始。
- 磁带式播放器：播放时卷轴转动，切歌时开盖、取带、装带、合盖；换带期间支持连续切歌与停止。机械按键、舱盖和换带音效在本地合成，电源灯旁的 ♪ 可独立关闭并记住选择；静音同时关闭音乐和音效。
- 按 `/` 或 `Ctrl/⌘ + K` 定位搜索，`Esc` 清空关键词；中文输入组词完成后更新结果。
- 分类、关键词和页码保留在地址栏，支持刷新恢复、收藏当前结果地址和浏览器前进/后退。
- 点击页码或底部「跳至」直接换页；搜索工具栏保持在目录顶部，不遮挡页面内容。
- 舒适/紧凑显示可切换并记住偏好；收藏操作显示反馈，8 秒内可撤销（悬停或键盘聚焦时延长）。

## 后台

- **黑胶音源**：添加、编辑名称和 LX 脚本直链、启用或停用、上下排序、删除，最多 32 项。聆听室刷新或重新检测后使用最新配置；优先尝试用户上次选择的有效音源，再按后台顺序检测。

- **网站管理**：新增、编辑、删除、显示/隐藏、NEW 标记、移动分类、上下排序。
- **批量管理**：当前页全选、跨页选择、批量显示/隐藏、移动、删除；切换筛选条件会清空选择。
- **分类管理**：两级分类增删改、调整父目录、同级排序。删除分类前显示将删除的网站/子分类数量。
- **热门推荐**：从目录添加、移除、排序。删除网站自动清理对应引用，隐藏网站不出现在前台推荐里。
- **精选网站 / 友情链接**：独立增删改、排序、显示/隐藏；精选可选择现有封面或不使用封面。
- **站点设置**：首页标语、公告、推荐/精选栏目名称、修改密码。
- **备份与恢复**：导出完整 JSON、校验备份、确认恢复范围后替换数据；不包含账号与个人收藏。
- **撤销**：在当前登录会话内撤销上一次目录或设置修改。刷新数据或退出登录后不保留此撤销入口。

每次保存即生效。前台重新获得窗口焦点或刷新后加载最新数据。已有窗口不会在后台自动轮询。

## 数据与迁移

原有 **488 条网站、8 个一级分类、21 个子分类、5 个精选与 2 个友链**全部作为初始数据保留。

| 文件 | 用途 |
| --- | --- |
| `data/store.json` | 当前完整目录与设置，后台所有修改的唯一存储来源 |
| `data/navigation.json` | 原始目录种子；仅在 `store.json` 不存在时读取 |
| `data/page-content.json` | 原始推荐、精选、友链种子；仅首次初始化读取 |
| `data/.private/account.json` | 管理员密码哈希与随机盐，不存明文密码 |
| `data/.private/previous-store.json` | 服务器自动保留的上一次保存版本 |
| `data/mp3/` | 公共电台读取的本地 MP3 文件；文件名会显示为曲目名 |

初始化后请通过后台修改内容，不要继续编辑种子文件。`store.json` 使用临时文件写入后原子替换；保存前检查版本号，多个管理窗口不会静默覆盖彼此修改。请仅运行一个指向同一 `data` 目录的服务器进程。

备份只包含目录与设置，不含密码或浏览器收藏。后台导入前显示记录数量并要求确认；服务器再次验证整个文件。文件最大 8 MB，最多 20000 条目录网站。自动保留的上一版本也可以作为完整 JSON 备份通过后台恢复。

会话保存在服务器内存中，连续闲置 30 分钟或达到 8 小时最长时限后过期，重启服务后需要重新登录。密码使用 scrypt 与随机盐存储；Cookie 为 HttpOnly/SameSite=Strict。修改密码使其他会话立即失效。连续登录失败 8 次后暂时限制该本地地址 15 分钟。

服务器只提供显式允许的页面、脚本和图片；原始数据文件、账号文件、服务端代码和备份目录不能通过静态 URL 下载。管理接口检查登录状态；写入接口检查请求来源、内容类型、URL 协议、ID 唯一性、分类深度与推荐引用。

如忘记管理员密码：先停止服务，妥善备份 `data/.private/account.json`，将该文件移出 `.private` 后重启服务，再在后台创建新账号。不要删除 `store.json`，网站数据无需重置。

也可以使用命令行直接重置密码。请先停止正在运行的服务，然后执行命令并按提示输入两次新密码（输入内容不会回显）：

```sh
npm run reset-admin-password
```

数据目录不是默认的 `data` 时可指定 `--data-dir /path/to/data`；自动化场景可使用 `--password-stdin` 读取标准输入的两行相同密码。命令只更新 `.private/account.json` 中的密码哈希和盐，不改变管理员用户名或站点数据；完成后重新启动服务。

如只想确认手头的密码是否正确，可执行：

```sh
npm run check-admin-password
```

它只输出“匹配”或“不匹配”，不会显示密码、哈希或随机盐；自动化场景可追加 `--password-stdin`，读取标准输入的第一行。

## 检查

```sh
npm run check
```

运行所有 JavaScript 语法检查、原始与当前目录数据校验、单元及 HTTP 集成测试。测试使用系统临时目录，不修改实际账号或导航数据。覆盖目录增删改/跨分类移动、批量删除与引用清理、持久化与重启恢复、备份、登录权限、密码轮换、冲突写入、跨站请求和静态文件保护。

本项目无需编译或安装依赖；`npm run check` 是交付前检查入口。

## 文件结构

- `index.html` / `app.js`：前台页面与交互。
- `admin.html` / `admin.js`：后台页面、表单与操作流程。
- `styles.css` / `admin.css`：共享复古视觉与后台布局。
- `navigation-data.js`：共享目录验证、搜索、收藏逻辑。
- `management-data.js`：共享目录修改操作，直接修改真实分类记录。
- `ui.js` / `radio.js`：公共界面工具与本地 MP3 / 合成旋律电台。
- `start-menu.js` / `minesweeper.js` / `snake.js`：Win98 开始菜单与附件小游戏。
- `server.js`：本地 HTTP 服务、账号、会话、校验与文件持久化。
- `scripts/reset-admin-password.mjs` / `scripts/check-admin-password.mjs` / `server/admin-account.js`：停止服务后从命令行重置或校验管理员密码及其账号文件。
- `assets/layers/`：保留原项目的透明图片素材。

目录来源信息保留在数据的 `source` 中。现有链接未逐一验证在线状态；站内热门推荐是人工整理，不代表实时访问排行。

## 慢放 · 黑胶聆听室

双击 Win98 桌面的「唱片机」图标（键盘 Enter 也可），或从首页菜单「黑胶聆听室」进入，地址为 `http://localhost:3000/listening-room.html`。保留原有 CD 网站收藏墙，音乐使用独立的聆听空间。

- 唱片机正对用户放在木质桌面上，背景为木质唱片架，桌面配有软盘、CD 盒、磁带、便签与圆珠笔等千禧年杂物。页面操作集中在机身，不设独立播放栏和解释文案。唱片机使用 CSS 3D 的顶板、前板、侧板、机脚、铰链、透明盖、转盘和唱臂；机身机械键负责播放、暂停、停止、切歌、唱片墙切换和搜索，旋钮支持拖动、滚轮与键盘调节音量。搜索使用桌边纸质「唱片目录」，音源设置保留在机身抽屉内。
- 首次进入会将 `data/mp3/` 的现有歌曲放上唱片墙。点击桌边「唱片目录」或机身放大镜打开目录，可搜索网易云歌曲，也能重新添加移除过的本地唱片。
- 封套具有纸纤维、压边、厚度与轻微磨损；点击唱片后依次取套、抽盘、落盘和落针，切歌前抬起唱臂并将旧盘归架。转盘在落针前启动，唱臂随播放进度缓慢向内移动，暂停后转盘停止。支持切歌、停止、进度拖动、音量、静音和机盖开合。启用系统减少动态效果时跳过过渡动画。
- 收藏和音量、音源、机盖偏好保存在本浏览器；唱片墙与聆听室共用收藏，其他同源标签页通过 storage 事件同步。切换聆听室和唱片墙不会打断播放。

### 纸质唱片目录

搜索目录独立于唱片机的 3D 缩放，保持正向、清晰的字号与滚动区域；窄屏使用适配屏幕高度的纸页。机身放大镜、桌边目录、唱片墙空位都能打开，也支持 `/`、`Ctrl/⌘ + K` 聚焦搜索，`Esc` 合上并返回入口焦点。在唱片墙中打开目录不会离开唱片墙。

- 「找唱片」输入歌曲名或歌手，停顿 450 毫秒后查询，也可按 Enter 或点击「查找」；中文输入法组词期间不请求。空关键词展示本地与已收藏唱片。
- 点击封面、曲名或「播放」可直接取片播放，无需先收藏。「上架」同步到背景和唱片墙，已上架结果不会因再次点击而移除；「我的唱片架」支持本地筛选和明确的「取下」操作。
- 结果显示歌手、专辑与本地来源，支持清空、翻页与失败重试。旧查询会取消，迟到的响应不会覆盖新结果；关闭目录取消待发和进行中的查询。
- 最近 12 个搜索页缓存 60 秒，重复查询复用结果；失败翻页保留已展示的唱片，重试继续同一页。

### 渲染与加载性能

- 首屏只创建最多 10 张背景封套；打开唱片墙时再创建完整收藏，重复打开和同列数的窗口缩放复用现有节点。收藏上限为 500 张。
- 屏外唱片行使用 `content-visibility` 延迟渲染，远程封面懒加载并异步解码。
- 播放时间、进度和唱臂角度仅在值变化时更新；角度样式只作用于唱臂，避免影响整个机身。后台标签页暂停 CSS 装饰动画和进度绘制，音乐继续播放，返回后同步显示。
- 音源切换复用当前页面已下载的运行脚本，每个候选音源仍使用新的隔离 iframe/Worker。
- 自动化测试覆盖 500 张收藏按需创建、节点复用、后台恢复和运行脚本缓存；未进行帧率、GPU 或真实设备性能测量。

### 透明机盖歌词投影

播放时，歌词直接投射在透明机盖上：当前句亮起，前后句淡出，暂停后变淡；开合盖子时文字随玻璃一起翻转并保持正向可读。停止、切歌或无时间轴歌词时收起投影。支持拖动进度、翻译歌词与系统减少动态效果设置，只在歌词换句时更新文字，后台标签页不绘制歌词。

- 网络歌曲按网易云歌曲 ID 读取歌词，与播放地址解析音源独立。
- 本地歌曲优先读取 `data/mp3/` 中与 MP3 同名的 UTF-8 `.lrc` 文件，例如 `歌名 - 歌手.mp3` 对应 `歌名 - 歌手.lrc`。没有文件时，仅按歌名、歌手一致且时长差不超过 3 秒的结果自动匹配；不上传音频。无法匹配或网络不可用时保持透明盖面，音乐继续播放。
- 只读接口为 `/api/listening/lyrics`；网络歌词最多缓存 100 首、15 分钟。本地 MP3 支持流式分段读取，跳转进度时不必重新读取整首文件。
- 实现位于 `public/lyrics.js`、`public/lyrics.css` 和 `server/listening-service.js`。重启服务并刷新聆听室后生效。

### 网络音源

默认音源目录使用 [pdone/lx-music-source](https://github.com/pdone/lx-music-source) 的八个 `latest.js` 链接：Huibq、SixYin、Flower、LX、ikun、Grass、Juhe API、QDY。进入聆听室即自动检测：优先上次选中的音源，再按目录顺序尝试，选中并记住首个通过检测的音源。检测使用最多两首已收藏的网络歌曲，没有可用收藏时通过现有搜索接口取得检测曲目；必须完成脚本初始化、网易云平台和音质检查、播放地址解析，以及独立静音音频元素的 `canplay` 检查才算通过。检测不调用播放，不修改本地唱片或打断当前音频；每个音源最多检测 22 秒，单首曲目的解析和加载最多 7 秒。旋钮灯闪黄表示检测中，绿色表示通过，红色表示失败。展开机身天线旋钮可手动选择音源，电源图标可重新自动检测；手动选择会取消旧检测。服务端缓存脚本 15 分钟。支持按照 [LX 自定义源协议](https://lxmusic.toside.cn/desktop/custom-source) 的 `inited`、`request`、`musicUrl`、Buffer、MD5、AES、RSA 和 zlib 能力调用脚本。源更新提示不自动执行更新，也不弹出外部页面。

管理员可在「黑胶音源」中维护目录，脚本地址须为公网 HTTP / HTTPS 的 LX 自定义源 JavaScript 直链。配置保存在 `data/store.json` 的 `musicSources` 字段，并纳入备份与恢复；旧备份未包含该字段时保留现有配置。首次使用旧版数据时提供默认八个音源，主动删除全部音源或全部停用后不再自动补回，本地唱片仍可播放。脚本地址修改会使用新的服务端缓存条目，删除或停用后服务端拒绝继续获取该音源。

这些脚本主要解析音乐播放地址，不提供歌曲搜索。独立搜索适配按照 LX 的网易云 EAPI 查询协议获取歌曲元数据，保留 `source/songmid/singer/albumId/types` 等字段后传给音源。只展示真实搜索结果；平台失败时显示错误，不以样例结果替代。

脚本运行在不带 `allow-same-origin` 的 sandbox iframe 所创建的独立 Worker 中，不在 Node 服务端执行。iframe/Worker 禁止直接连接网络或访问主页面存储，网络调用经受限桥接转发；桥接限制方法、大小、并发和超时，解析并固定公共 IP，每次重定向重新校验，阻止本机、内网和保留地址。跨域写请求继续被主服务拒绝。主站的 CSP 不变，仅聆听室允许远程音频和封面。

通过检测表示至少一首检测曲目当时可以加载，不保证所有歌曲始终可用。服务停机、限流、密钥失效、地区限制或音频格式不支持会导致检测失败并自动尝试下一音源。全部失败时保留本地播放和手动重试；不会回退为模拟音乐或把失败当作成功。2026-09-07 的非浏览器检查确认真实搜索能返回结果、Huibq 脚本可下载，但其播放解析端点返回 HTTP 503。其他第三方音源的实时可用性未逐个验证。

### 一起听 · 同频聆听室

入口为 `/together.html`（也支持 `/together`），首页菜单与黑胶聆听室右上角均提供链接。页面直接嵌入黑胶聆听室原页面的共享模式，复用同一份唱片机 HTML、CSS 和交互代码；旁边保留入场券式房间面板，支持手机布局。

1. 输入昵称，创建房间，复制邀请链接给朋友；朋友输入昵称并加入。也可以直接输入 8 位房间码。
2. 在原唱片墙选择本地唱片，或翻开原唱片目录搜索网络歌曲。复用黑胶聆听室的 `/api/radio`、音源管理目录、LX 沙箱和自动音源检测；网络曲目解析并读取时长成功后才提交给房间，所有成员使用同一个音频地址。
3. 使用原机身机械按键播放、暂停、上一首、下一首或停止，也可以拖动原显示屏进度条；这些操作同步到全房间。机盖开合、旋钮音量、静音、音源抽屉、唱片收藏和歌词投影沿用原有操作，音量与机盖仅影响本人。浏览器禁止自动播放时，按机身播放键或点击「打开声音」。曲目结束后点击播放可重听。

`public/listening-shared.js` 为原播放器提供房间传输适配层；房间页仅管理成员和权威状态，不再另建一套播放器。换碟和落针动画完成后追赶最新房间时间，远端更新不会反向触发新的播放操作。

同步服务位于 `server/together-service.js`，每个 Node 进程保存最多 300 个房间、每房间最多 20 人。浏览器通过 `GET /api/together/stream` 订阅服务端权威状态（SSE），服务端在换歌/暂停/进退成员时推送，并每 15 秒心跳一次以刷新成员在线；推送不可用时回退到约 1 秒一次的 HTTP 轮询。位置以请求往返时间补偿和本地单调时钟推算；超过 1 秒的偏差直接校正，较小偏差用轻微变速追赶。操作采用版本校验，避免慢速音源解析覆盖其他人的新选曲。成员令牌只出现在请求头，不出现在分享链接或成员列表中。

页面切到后台或进入 bfcache 时不会主动断开房间或暂停共享音频；隐藏页面上的换碟会跳过飞碟/落针动画，直接装载音频并对齐进度。回到前台会立即拉取最新状态并尝试解锁自动播放。房间 1 小时无人请求后过期，成员断联 45 秒后移出（SSE 心跳与轮询都会刷新在线）；重启服务会清空房间。标签页被系统完全丢弃后仍需重新打开页面。公网多人使用需要把此 Node 服务部署在同一个可访问地址下，通过现有反向代理将 Host 转给 localhost；仅本机 localhost 预览链接不能供其他设备访问。多进程部署需保持所有房间请求落在同一进程，当前未使用共享数据库。外部音源失效时可重新点歌或选择其他音源。

新增同步和 HTTP 测试：`tests/together.test.js`、`tests/server.test.js`；`npm run check` 包含新模块的语法检查。
